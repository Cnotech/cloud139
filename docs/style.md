# 代码约定

- 按职责命名文件，省略目录已经表达的类别，例如 `services/list.rs` 和 `presentation/sync.rs`。目录模块的 `mod.rs` 主要声明子模块，紧邻模块入口的实现可以留在其中。
- 从类型、函数或常量的定义模块导入，公开 API 优先定义在其对外入口。平台实现选择或导出宏访问依赖需要重导出时，使用所需的最小可见范围并说明原因。
- 条件操作的名称写明触发条件，涉及持久化时体现副作用。例如 `refresh_token_if_due` 在触发续期时返回更新后的配置，`refresh_saved_token` 将结果写回配置文件。布尔判断用 `is_` 或 `has_`。
- 普通注释、文档注释和测试注释使用简体中文，代码标识符、协议字段及工具识别标记保留原样。
- CLI 适配器把错误交给入口处理，库通过 `Result` 返回错误。修改公开 API 或 CLI 参数时考虑现有调用方。删除已公开的接口属于破坏性变更，发布时按 SemVer 处理并记录迁移方式。
