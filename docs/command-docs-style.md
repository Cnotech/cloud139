# 命令文档约定

参数名、短选项和默认值以 [CLI 参数定义](../packages/cli/src/cli.rs)及对应命令的 `--help` 为准。操作语义、参数组合限制和退出码以命令实现与相关测试为准。

- 命令参考依次写用途、语法、参数表和示例。根命令的通用选项集中在 README 的「全局选项」，各子命令语法只列本命令的选项。
- 语法中用 `<参数>` 表示必填，用 `[参数]` 表示可选。可重复的位置参数使用 `...`，例如 `<源路径...>`。位置参数用简明中文命名，同一命令的语法和参数表采用相同名称。凭据可用 `<TOKEN>` 作占位符。
- 参数表列出参数、简写、是否必填和说明。有默认值或条件限制时写在说明中，例如删除目录需要同时提供 `--yes` 和 `-r`。
- 示例从常用场景开始，使用具体路径。每条命令上方用中文注释说明用途，示例之间留空行。有简写且含义清楚时可优先使用。快速开始与命令参考遵循同一组默认值和行为。

```sh
# 列出根目录
cloud139 ls /

# 每页 50 条，查看第 2 页
cloud139 ls / -p 2 -s 50
```
