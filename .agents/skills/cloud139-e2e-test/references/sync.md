# 同步、内容校验和 JSON 报告

使用[真实测试环境](real-run.md)。在 `"$LOCAL/sync-source"` 复制 `"$FIX/sync-source"`，令 `SYNCSRC` 指向该副本，`SYNCDST="$LOCAL/sync-download"`，`REMOTE="$CLOUD/s11/target"`。先建好 `REMOTE`。每个独立场景使用 s11 下的新目标。

普通本地到云端同步按文件大小判断是否需要上传。同大小内容变更用 `--verify` 检测。它只支持本地到云端，并发固定为 1。普通模式并发默认 4，范围 1–32。同步预演会扫描目录，CLI 仍可能续期凭据。报告字段见 [README](../../../../README.md#sync)。

| 用例 | 操作 | 预期 |
| --- | --- | --- |
| 11.1 | `c139 sync "$SYNCSRC" "cloud:$REMOTE"`，再加 `-r`。 | 均为 0，先上传根下两个文件，再补齐子目录文件和空目录。最终清单一致。 |
| 11.2 | 重复递归同步。 | 0，无新增传输，完整清单不变。 |
| 11.3 | 将本地 `file1.txt` 改为不同大小，执行 `c139 sync -r -n "$SYNCSRC" "cloud:$REMOTE"`。 | 0，计划显示更新。下载核对云端内容未变。 |
| 11.4 | 去掉 `-n` 执行 11.3。 | 0，只更新预期文件，清单一致。 |
| 11.5 | 从本地移除 `file2.txt` 和空目录 `empty`。先做普通递归同步，再加 `--delete -n` 预览。 | 两次均为 0。普通同步保留多余对象，预览列出待删除项，实际云端清单不变。 |
| 11.6 | 去掉 `-n` 执行 11.5 的清理计划。 | 0，只清理此目标中的多余对象。轮询并比对清单。 |
| 11.7 | 新源包含 `.env`、`output.log`、`subdir`、`kept.txt`。预建空目标后同步，传 `-r --exclude '*.log' --exclude '.env' --exclude 'subdir'`。 | 0，目标只有 `kept.txt`，哈希一致。 |
| 11.8 | 用新源和已建好的空目标，先后以 `-r -j 2`、`-r -j 8` 同步 8 个小文件。 | 均为 0，首次传输完整，第二次清单不变。 |
| 11.9 | `c139 sync -r "cloud:$REMOTE" "$SYNCDST"`，然后重复。 | 均为 0，下载清单一致，第二次无新增传输。现有目标仍以该路径作为同步根。 |
| 11.10 | 将 `SYNCDST/file1.txt` 改为不同大小，再做 11.9。 | 0，恢复云端内容，哈希一致。 |
| 11.11 | 以缺失的本地目录作源，另分别试两端均本地和两端均云端。 | 均为 2，报告扫描或方向错误，未创建对象。 |
| 11.12 | 用缺失的 `"$CLOUD/s11/not-created-dir"` 作云端同步根。 | 2，目标必须先创建。 |
| 11.13 | 在独立目标上传 `same-v1/same.bin`，以 `"$FIX/same-v2"` 作源，先普通同步，再加 `--verify --json`。内容验证通过后，以 `EXECUTE_LIST_LIMIT=0` 再执行一次相同的校验同步。 | 均为 0。普通同步保留 AAAA，校验同步的单行 JSON 中有 `same.bin` 的 `upload`，最终下载为 BBBB。重复校验报告跳过 1 个文件，汇总日志核对执行阶段零次 `/file/list`。 |
| 11.14 | 为 11.13 的目标新增并登记一个多余文件和空目录。先用 `-r -n --verify --delete --json`，再去掉 `-n`。 | 均为 0。预览 `dryRun: true`，`changes` 为空，`plan` 包含 `verify` 和文件的 `delete`，云端不变。执行后报告删除该文件，保留空目录及 BBBB。 |
| 11.15 | 预建独立目标，以 `"$FIX/files/a.txt"` 作单文件源执行 `sync --json`，再加 `--delete`。 | 首次 0，目标含 `a.txt` 且哈希一致。第二次 2，报告单文件不支持 `--delete`，前后清单不变。 |

使用 `--json` 时校验 stdout 只有一行 JSON，日志走 stderr。部分失败、清理中断、等大小文件、报告字段及保护恢复副本的断言见[离线用例](offline.md#同步和清理)。
